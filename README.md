# Nexo Freelance OS

Demo funcional local para gestionar y proyectar ingresos freelance. El nombre visible vive en configuración y metadata para poder renombrarlo sin tocar el dominio.

## Desarrollo

```bash
npm install
npm run dev
```

La información se persiste localmente. **Restaurar demo** en Configuración recupera las semillas. Véanse `docs/` para modelo, flujos y conexión futura con Supabase.
